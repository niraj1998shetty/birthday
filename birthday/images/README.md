# Drop your photos here

- `memories/1.jpg`, `memories/2.jpg`, `memories/3.jpg`, `memories/4.jpg` — swipeable memory cards
- `hero-cake.png` (optional) — hero illustration on the welcome screen
- `bouquet.png` — rose bouquet on screen 5 (already here; regenerate from `bouquet.jpg` with `tools\make-png.ps1`)
- `scratch-reveal.jpg` (optional) — the surprise photo under the scratch card (dummy gift emoji + text shown until you add this)
- `puzzle-photo.jpg` (optional) — the photo assembled by the tap-to-reveal puzzle tiles (dummy pink gradient shown until you add this)
- `polaroid-1.jpg` (optional) — the photo that develops in the photo booth polaroid (dummy gradient + 💑 shown until you add this)

Portrait images (~800×1000px) work best for memory cards. The site works fine without any of these — you'll just see cute emoji placeholders.
